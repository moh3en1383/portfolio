پلتفرم ارزیابی و تحلیل سازمانی Scanbusiness

پلتفرم جامع و حرفه‌ای برای ارزیابی عملکرد سازمان‌ها با استفاده از مدل‌های معتبر بین‌المللی و چارچوب‌های مدیریتی.

درباره‌ی پروژه

این پلتفرم به سازمان‌ها کمک می‌کند تا نقاط قوت و ضعف خود را شناسایی کرده و مسیر بهبود مستمر را طی کنند. سامانه با معماری ماژولار، API RESTful مستندسازی‌شده و پشتیبانی کامل از زبان فارسی و تقویم جلالی طراحی شده است.

معماری و تکنولوژی‌ها

  • Backend: Laravel 11 با PHP 8.2+ و معماری ماژولار
  • Authentication: Laravel Sanctum برای API Authentication
  • پایگاه داده: MySQL با ساختار ماژولار
  • Frontend: Nuxt.js و TypeScript
  • ابزارها: Laravel Telescope، Maatwebsite Excel، PhpOffice PHPWord

مدیریت سازمانی

  • پنل مدیریت (Admin Panel)
  • مدیریت کارکنان
  • مدیریت کمیته‌ها
  • مدیریت واحدهای سازمانی
  • مدیریت پلن‌ها

سیستم پرسشنامه

  • طراحی و مدیریت پرسشنامه‌ها
  • پاسخ‌نامه‌های آزاد و ساختاریافته
  • ثبت و تحلیل پاسخ‌ها

سیستم پرداخت

  • اتصال به درگاه‌های پرداخت
  • مدیریت تراکنش‌ها و اشتراک‌ها بر پایه‌ی پلن

سایر امکانات

  • سیستم OTP برای احراز هویت
  • مدیا لایبرری برای مدیریت فایل‌ها
  • خروجی اکسل و Word
  • پشتیبانی از تقویم جلالی
  • سیستم تماس با ما
  • تنظیمات پیشرفته

ویژگی‌های فنی برجسته

  • معماری ماژولار با قابلیت توسعه آسان
  • API RESTful با مستندسازی کامل
  • سیستم Permission و نقش‌های کاربری
  • پشتیبانی از زبان فارسی و تقویم جلالی
  • گزارش‌گیری پیشرفته و تحلیل داده‌ها
  • رابط کاربری حرفه‌ای و کاربرپسند

نقش من و دستاوردها

  • طراحی و پیاده‌سازی بک‌اند ماژولار و APIهای مورد استفاده در فرانت‌اند Nuxt
  • پیاده‌سازی احراز هویت با Sanctum و OTP و مدیریت نقش‌ها و مجوزها
  • ساخت موتور پرسشنامه و گزارش‌گیری با خروجی اکسل/Word
  • یکپارچه‌سازی درگاه پرداخت و مدیریت پلن‌های اشتراکی
