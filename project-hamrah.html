همراه هوشمند — دستیار هوش مصنوعی فارسی

رابط کاربری یک پلتفرم عامل هوش مصنوعی فارسی برای فکر کردن، نوشتن، تحلیل کردن و ساختن؛ با تجربه‌ی گفت‌وگوی راست‌چین مدرن و عناصر سه‌بعدی زنده.

درباره‌ی پروژه

«همراه هوشمند» یک وب‌اپ تک‌صفحه‌ای (SPA) است که با React 19 و TypeScript ساخته شده و تجربه‌ی گفت‌وگویی کامل فارسی را ارائه می‌دهد. طراحی با دقت روی RTL، تایپوگرافی فارسی و پاسخ‌گویی کامل موبایل انجام شده است.

تجربه‌ی گفت‌وگو و محتوا

  • رابط گفت‌وگوی راست‌چین با فونت Vazirmatn به‌صورت متغیر و بهینه
  • رندر Markdown پاسخ‌ها با marked و برجسته‌سازی کد با highlight.js
  • مسیریابی سمت کلاینت با React Router و ساختار چندصفحه‌ای

جلوه‌های سه‌بعدی

  • استفاده از Three.js برای عناصر تعاملی سه‌بعدی در صفحه
  • بهینه‌سازی رندر و بارگذاری برای اجرای روان روی موبایل

معماری و ابزارها

  • React 19 + TypeScript با ساختار کامپوننتی و تایپ‌محور
  • ابزار ساخت Vite برای توسعه‌ی سریع و بیلد بهینه
  • اسکریپت check:fa برای بررسی صحت متن‌ها و وضعیت فارسی‌سازی
  • تایپ‌چک سخت‌گیرانه (tsc --noEmit) به‌عنوان بخشی از فرآیند بیلد

نتیجه

این پروژه سمت فرانت‌اند من را نشان می‌دهد: کار با اکوسیستم مدرن React، TypeScript، گرافیک سه‌بعدی وب و رعایت اصول طراحی رابط کاربری فارسی و راست‌چین.

اطلاعات پروژه

  • نوع: وب‌اپ / SPA
  • نقش: توسعه‌دهنده فرانت‌اند
  • حوزه: هوش مصنوعی
  • وضعیت: نمونه‌ی اولیه
