سامانه مدیریت تعمیرگاه

CRM ماژولار برای مدیریت تعمیرگاه‌های الکترونیک؛ از پذیرش و پیگیری تعمیرات تا فروش، انبار و مدیریت دسترسی‌ها — با معماری ماژولار و رابط کاربری جداشده.

درباره‌ی پروژه

این سامانه با معماری ماژولار ساخته شده است تا هر بخش از کسب‌وکار تعمیرگاه به‌صورت مستقل توسعه و نگهداری شود. فرانت‌اند از بک‌اند جدا شده و بک‌اند از طریق API با آن ارتباط می‌گیرد.

معماری ماژولار

  • ماژول‌های مستقل: Admin، Auth، Captcha، Catalog، Customer، Dashboard، ManagePermission، RepairOrder و Sales
  • توسعه بر پایه‌ی سیستم ماژولار Laravel با امکان افزودن ماژول جدید
  • فرانت‌اند مجزا (پروژه‌ی repaircrm-frontend) متصل به API

مدیریت تعمیرات و فروش

  • پذیرش دستگاه، ثبت سفارش تعمیر و پیگیری مراحل
  • مدیریت مشتریان و سوابق تعمیرات آن‌ها
  • کاتالوگ قطعات و خدمات + انبار
  • فروش و صدور فاکتورهای فروشگاه

امنیت و دسترسی

  • سیستم مدیریت نقش‌ها و مجوزها (ManagePermission)
  • احراز هویت و محافظت با کپچا
  • دسترسی مبتنی بر نقش برای هر بخش از سیستم

نتیجه

این پروژه بر معماری تمیز و تفکیک دغدغه‌ها (Separation of Concerns) تمرکز دارد؛ ماژولار بودن آن اجازه می‌دهد سیستم بدون بازنویسی، برای کسب‌وکارهای مشابه گسترش پیدا کند.
